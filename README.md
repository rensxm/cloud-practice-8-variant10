# Файлдарды басқару жүйесі

Файлдар туралы мәліметті сақтауға, қарауға, қосуға және өзгертуге арналған бұлттық жүйе жасалды. Қазақша интерфейс Express API және PostgreSQL базасымен байланыстырылды. Деректерді тексеру, қауіпсіз SQL сұраныстары, қателерді өңдеу, қызмет күйін бақылау және журналдау іске асырылды. Жүйе Render-де жарияланып, негізгі әрекеттері тексерілді.
